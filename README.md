# Geethmi Fernando | Portfolio

Personal portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Edit your content

All text lives in `src/data.js`. Change your links, projects and skills there. You do not need to touch the components.

## Deploy

Push to the `main` branch. In the repo go to Settings > Pages and set Source to "GitHub Actions". The included workflow builds and publishes the site.
